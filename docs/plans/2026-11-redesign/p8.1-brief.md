## 3. Backend

### 3.1 Storage: why nothing new

DATA_SOURCES.md: the OpenF1 read-through never stores `position` or `overtakes`. The rewind therefore keeps those two **measured inputs** in the existing `analysis_cache` once the race has ended and settled (`session_ended`), exactly as `debrief_overtakes._rows` already does for overtakes. `analysis_cache`'s rule is "measured input, never a modelled result", so the computed payload is **not** stored:

- the derivation is cheap (≈560 position rows, ≈1,300 laps) and every other input is already cached (`load_session_laps` in `analysis_cache`, `pit` in the read-through, `race_classification` in its TTL cache, FIA documents in their store);
- the Final step must pick up a late stewards' decision; a stored payload would freeze the pre-decision classification.

Kinds: positions under `"race_positions"`, version 1, key `f"{year}:{round}"`, payload `{"rows": rows}`. Overtakes under the Debrief's own `OVERTAKES_KIND` / `OVERTAKES_VERSION` (imported from `app.services.debrief_overtakes`, same key and payload shape), so one stored copy serves both pages. Never store an empty answer or an unsettled session.

### 3.2 `backend/app/services/rewind_order.py` (pure, no I/O)

Everything here takes plain data and is tested on the R19 fixtures and hand-built cases.

- `crossings(laps) -> dict[(car, lap), datetime]`: a car crosses the line at the end of lap L at **its next lap's start**, else at `lap.end` (start + time). (The Debrief's `_crossings` prefers `lap.end`; the rewind follows the reference derivation, which samples on the next start.)
- `SAMPLE_LAG = timedelta(seconds=1)` with the comment `# shortcut: OpenF1 stamps the new place just after the line; 1 s matches the reference derivation on R19, revisit if a race reads wrong`. `place_at(samples, moment)`: the last `position` row of that car at or before `moment + SAMPLE_LAG` (bisect on the sorted dates; the first row when none is earlier).
- `lap_orders(laps, position_rows, finishers) -> list[list[int]]`: for each lap 1…total, the cars with a crossing for that lap, sorted by sampled place, ties by crossing time. At the last lap, also each car in `finishers` (classified `finished`) whose last crossing is earlier (a lapped car), placed by its sample at that last crossing. A running car with no crossing on a lap it ran is left out of that lap (R19 has none; a test proves it).
- `STOP_LANE_FACTOR = 1.5` (comment: `# a lane time over 1.5 × the race's median is a red-flag entry or a restart wait, not a stop`). `real_stops(pit_rows, codes) -> list[(code, lap)]`: `lane(row) = row["lane_duration"]` if not `None`, else `row["pit_duration"]`; `median` = `statistics.median` of `lane(row)` over every row with a lane time (none → no stops); a stop = a row with a lane time below `STOP_LANE_FACTOR * median` (`stop_duration` not needed). Rows for a car missing from `codes` are skipped. R19: median 27.9 s, limit 41.9 s; none on lap 45 or lap 1.
- `overtake_laps(rows, laps) -> dict[lap, set[frozenset[code]]]`: each OpenF1 overtakes row on the lap the **overtaking** car was on at `date` (its latest lap with `start <= date`); rows without either car or a date are skipped.
- `track_status(neutralisations, lap)`: `"red"`, `"sc"` or `"vsc"` when a range covers the lap (that precedence), else `None`. Ranges come from `app.data.race_neutralisations.lap_ranges(session.laps, session.windows)` (the Debrief's source).
- `classify(code, lap, prev, cur, stops, passes, status) -> dict`: places are ranks in `prev` (previous lap's order, or the grid order for lap 1) and `cur`. `stopped(m)` = m has a real stop on lap L−1 or L. `swapped` = cars in both orders whose order relative to `code` flipped, by previous place. First match wins:
  1. `own_stop` — `stopped(code)`; `stop_lap` = its latest stop ≤ L.
  2. `rival_stop` — a swapped car `stopped`; `rival` = the first such, `stop_lap` = its stop.
  3. `retirement` — `code` gained places and a car ahead of it in `prev` is missing from `cur`; `rival` = the first such.
  4. `neutralised` — the lap has a `track` status (a non-stop change under SC, VSC or red flag is never a pass).
  5. `pass` — an overtakes pair on lap L joins `code` with a swapped car; `rival` = the first such.
  6. `change` — none of the above. Never labelled an overtake.
- `lap_changes(...)`: `classify` for every car whose place moved, sorted by new place.

### 3.3 `backend/app/services/race_rewind.py` (I/O and assembly)

```python
def build_race_rewind(year: int, round_num: int) -> dict: ...
```

1. `session = load_session_laps(year, round_num, "R")`; `None` or no laps → `_unavailable("OpenF1 hasn't published this race's laps yet.")`.
2. `with new_client() as client:` `found = find_session(client, year, round_num, "R")`; positions and overtakes through `_kept_rows(client, found, endpoint, kind, version, key)` (§3.1); `pit = get_json(client, "pit", {"session_key": …})`. No position rows → `_unavailable("OpenF1 hasn't published this race's positions yet.")`. `OpenF1UnavailableError` propagates (the router turns it into the failure envelope).
3. Names: `canonical_entry(session.drivers[n], year)` for every entry (as `debrief_laps._driver` does).
4. Classification: `race_classification(year, round_num)` (FIA final → OpenF1 `session_result` → Jolpica). Its `drivers` give `status` and `laps`; `final.provisional = source != FIA_FINAL_SOURCE`. With `NO_CLASSIFICATION`, `final` is `None` and `status`/`laps` are `None`.
5. Penalty notes, only when the source is the FIA: `final_classification(year, round_num, "race")`; for each `note` in `.classification.penalties`, `who = final.driver(year, note.car, printed)` (printed = the entry's `driver` for that car, as `debrief_penalties._post_race_fia` reads it), `{ruling, seconds, document}` with `seconds` from `(\d+)\s+second\s+time\s+penalty` (case-insensitive). Group by code. `document`/`url` come from `.classification.document` and `.url`. Without the FIA document the rows carry no notes (the Provisional tag says why).
6. Grid: `build_starting_grid(year, round_num)` (`app.services.race_grid`); used when `available and not provisional` (the Debrief's `_grid_slots` rule): `order` = slotted cars by `position`, then `pit_lane` cars. Otherwise each car's first OpenF1 `position` row, `source: "openf1-position"`, `document: None`.
7. Orders and changes from §3.2; `road_position` = the car's place in the order of its last lap with a crossing (lap `total_laps` for a finisher, its own last lap for a lapped one; `None` for a car with no crossing).

Keep each function under 50 lines; the module under 400.
