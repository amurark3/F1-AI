## 1. Goal and scope

Each team-radio clip OpenF1 published for a race sits with the race moment it came within a lap of: the driver's own stop, penalty or retirement, or a race-wide moment (start, Safety Car, VSC, red flag, chequered flag). Each clip plays inline, one at a time, labelled as audio with no transcript. Clips that match no moment are listed in a collapsed group by lap, so nothing OpenF1 published is hidden.

**Out of scope (named, not built):** transcripts or any text "about" a clip; stewards' follow-ups ("REVIEWED", "WILL BE INVESTIGATED", "NO FURTHER ACTION") as extra moments; a filter by driver or team; download links; a waveform; autoplay or "play all"; the Debrief → Rewind link; Engineer use of radio (DATA_SOURCES lists it, a later task); caching the built payload.

## 2. API contract

`GET /api/race-control/debrief/{year}/{round}/radio` (router `backend/app/api/routers/race_control.py`, the `_debrief_part` pattern P6.1 uses for `/laps`, `/penalties`, `/overtakes`; builder `build_debrief_radio` in a new `backend/app/services/debrief_radio.py`). A failure answers the usual `client_error` envelope (HTTP 200, `error` + `error_id`) so `useSection` reports it as failed.

## 3. Backend (do it first)

### 3.1 Inputs and the I/O wrapper

Split the module into a pure part and a thin I/O wrapper, so tests and the fixture capture (§5) need no patching:

```python
@dataclass(frozen=True)
class RadioInputs:
    laps: SessionLaps            # session, year, drivers (entry list), laps (all cars), windows
    radio: list[dict]            # OpenF1 team_radio rows
    pit: list[dict]              # OpenF1 pit rows
    messages: list[dict]         # OpenF1 race_control rows
    gmt_offset: str | None       # OpenF1 sessions row's "gmt_offset", e.g. "-06:00:00"
    dnf_cars: frozenset[int]     # car numbers the classification lists as DNF

def radio_payload(inputs: RadioInputs) -> dict: ...
def build_debrief_radio(year: int, round_num: int) -> dict: ...
```

`build_debrief_radio`:
- `laps = load_session_laps(year, round_num, "R")` (analysis-cached, every car's laps, entry list, windows). `None` or no laps → unavailable, reason `"OpenF1 hasn't published this race's laps yet."`.
- One `new_client()` block, all through `get_json` with `{"session_key": laps.session.session_key}`: `team_radio` (empty → unavailable, reason `"OpenF1 has no team radio for this race."`, and no further requests), `pit`, `race_control`, `sessions` (first row's `gmt_offset`, `None` if no row or no key). The first three read through the D1.4 store; `sessions` is one un-stored request per build (§9 Q5).
- `dnf_cars`: `build_session_result(year, round_num, "race")` (the classification chain the Debrief already uses: f1db → FIA → OpenF1). Rows with `status == "DNF"`, matched to car numbers by `canonical_entry(entry, year).code == row["driver_code"]`. `None` → empty set. Never derive retirement from laps (accuracy rule).
- Keep a clip only if its `recording_url` starts with `RECORDING_ORIGIN = "https://livetiming.formula1.com/"` (validate at the trust boundary: it becomes an `<audio src>`), its `date` parses and its car is in the entry list. `total` counts kept clips.

### 3.2 Moments

Dates through `parse_iso` (`app.services.live_timing`). A moment is a frozen dataclass `Moment(kind, lap, at, car=None, detail=None, until=None)`.

- **Start:** `kind "start"`, lap 1, `at = laps.session.date_start` (the scheduled start; R19 20:00:00Z). Skip when it's `None`.
- **Race control** (only messages with a `lap_number` and a parseable `date`; R19's feed carries eight stray Saturday rows, and all but one have no lap), on the upper-cased `message`:
  - `"SAFETY CAR DEPLOYED"` prefix → `safety_car`; `"SAFETY CAR IN THIS LAP"` → `safety_car_in`;
  - `"VSC DEPLOYED"` / `"VIRTUAL SAFETY CAR DEPLOYED"` → `vsc`; `"VSC ENDING"` / `"VIRTUAL SAFETY CAR ENDING"` → `vsc_ending`;
  - `flag == "CHEQUERED"` → `chequered`;
  - **red flag:** reuse `neutralised_windows(messages)` (`app/data/openf1/race_control.py`): for each window with `kind == RED_FLAG`, the message dated exactly `window.start` is the moment, `kind "red_flag"`, its `lap_number`, `until = window.end` (`None` = never closed). R19: 21:06:02 → 21:45:00. Don't copy the red-flag rule.
  - **incident** (coordinator, Q1: PLAN says "stops, incidents, penalties"): a message containing `INCIDENT` and `NOTED` → one moment **per car it names** (`(\d+) \([A-Z]{3}\)`), `kind "incident"`, `car` = that car. `at` = the incident's own time in the trailing `(HH:MM:SS)` (circuit-local wall clock on the message's date, converted to UTC with the session's offset; no bracket or no offset → the message `date`); `lap` = that car's lap at `at` (same rule as a clip's lap). `detail` = parts joined by " · ": the `TURN n` prefix as "Turn n", "with " + the other named cars' codes, the reason after " - " capitalised (each part only when present). R19: "Turn 4 · with LEC" (HAM, L1), "Turn 2 · with LIN" (PIA, L59).
  - **penalty:** reuse `_MESSAGE` from `app/services/debrief_penalties.py` (private imports across modules already exist in the repo); a match whose `served` group is empty → `penalty`, `car = int(m["car"])`, `detail = m["penalty"].capitalize()` ("5 second time penalty").
- **Stops:** pit rows with a truthy `stop_duration` and a pit-lane time below `STOP_LANE_FACTOR = 1.5` × the race's median lane time over rows with a `stop_duration` (R19: median 23.5 s → limit 35.3 s), the lane time being `lane_duration`, else `pit_duration` (OpenF1 renamed it; see `edition_sources._lane_seconds`). Lane at or above the limit, or unknown, is **not a stop**: red-flag pit-lane entries (R19 L45, 2266–2315 s) and restart pit-lane waits (R19 cars 23, 30, 50, 55 just after the 21:45 restart, lane 55–61 s; coordinator, Q6). `kind "stop"`, row's `lap_number` and `date`, `detail = f"{stop_duration:.1f} s"`. Skip rows without a `date` or `lap_number`.
- **Retirements:** for each car in `dnf_cars` with laps, `kind "retirement"`, lap = its highest lap number, `at` = that lap's `start` (skip when `None`). A DNF car without laps gets no moment.

### 3.3 Matching

- **Clip lap:** the highest lap number among the clip driver's laps whose `start <= clip.at`; none → 0 ("before the start"). Precompute per-car sorted starts once. (`# shortcut:` a car with no laps at all reads lap 0; fine for a DNS, revisit if a car without laps ever radios mid-race.)
- **Candidates:** if the clip falls inside a red-flag window (`m.at <= clip.at` and (`m.until is None` or `clip.at <= m.until`)), the red flag(s) only: any clip during the suspension belongs to it. Otherwise every moment with `abs(m.lap - clip.lap) <= RADIO_WINDOW_LAPS` (1) and `m.car in (None, clip car)`.
- **Pick:** the candidate nearest in time (`abs((m.at - clip.at).total_seconds())`); on a tie, the earlier moment (`min` over moments sorted by `at`). No candidate → `unattached`.
- Output: moments with clips, by `at`; clips in each, and `unattached`, by `at` then `url`. Functions under 50 lines, the file under 300; immutable (build new lists/dicts, never mutate rows).
- `utc_offset_minutes` from `gmt_offset` via `re.fullmatch(r"([+-]?)(\d{1,2}):(\d{2})(?::\d{2})?", …)`; no match → `None`.

### 4.3 `useRadioPlayer.ts` (`"use client"`)

One `<audio>` for the whole section, so one clip plays at a time. Returns `{ audioRef, now, failed, toggle, handlers }`:
- `now: { url: string | null; playing: boolean; elapsed: number; duration: number | null }`, `IDLE` constant; `failed: ReadonlySet<string>` (replace the set, never mutate).
- `toggle(url)`: same url → `el.paused ? play : el.pause()`; another url → `el.src = url`, `now = { url, playing: true, elapsed: 0, duration: null }`, play. `play` = `el.play().catch(() => setNow(cur => cur.url === url ? IDLE : cur))` (a switch rejects the old promise with AbortError; only the current clip resets; a blocked play resets).
- Handlers for React media props: `onPlay` → playing true; `onPause` → playing false; `onTimeUpdate` → `elapsed = el.currentTime`; `onLoadedMetadata` / `onDurationChange` → `duration = Number.isFinite(el.duration) ? el.duration : null`; `onEnded` → `IDLE`; `onError` → add `now.url` to `failed`, `IDLE`.
- The element: `<audio ref={audioRef} preload="none" hidden {...handlers} />`. **No `crossOrigin` attribute**: the archive sends no CORS headers (checked 2026-11-23: `HTTP/2 200`, `content-type: audio/mpeg`, no `access-control-*`), and plain media playback doesn't need them. Removing a playing media element pauses it (HTML spec), so no unmount effect; §4.5 remounts the section per round.
- Coverage trap: a `if (!audioRef.current) return` guard is an uncoverable branch. Create the element lazily instead, or restructure; never an ignore comment.

**CSP:** none exists (`frontend/next.config.ts` sets only redirects and Sentry; no `headers()`, no middleware, `vercel.json` has none). Nothing to change. If a CSP is ever added, it needs `media-src https://livetiming.formula1.com`.
