# Design Philosophy

Expertise shows in what you decide; restraint shows in what you leave out. Generic output isn't ugly — it's undecided.

## Principles

1. **The content is the design.** Start from what the audience must understand, decide or do. Layout, type and color exist to make that faster. A choice that doesn't serve the message is decoration.
2. **Decide, don't default.** Calibri, the chart library's blue, 16px everywhere, a rounded card with a shadow — each default is a decision someone else made for a different context. Keeping a default is fine when you chose it.
3. **Spend boldness in one place.** Each piece gets one signature move: a giant number, a full-bleed color field, a hard crop, a dramatic jump in type size. Everything around it stays quiet so the move lands. Two bold moves compete; five is noise.
4. **Restraint is not blandness.** Bland means no decisions were made. Restrained means many decisions were made, most of them "remove". A restrained piece still has strong hierarchy, an exact grid and one point of tension.
5. **Hierarchy beats decoration.** When something needs emphasis, reach for size, weight, contrast, position and space before borders, icons, badges, shadows or extra colors.
6. **Systems create polish.** Most of what reads as "professional" is consistency: one type scale, one spacing scale, one radius, one accent, everything on a grid. Fix inconsistency before adding anything.
7. **Fit the room.** A board deck, an ops dashboard and a launch page have different jobs. Density, tone and boldness follow the audience and viewing conditions, not personal taste.
8. **Honor what exists.** A brand, design system or existing UI is a constraint, not an obstacle. Elevate within it. Never "improve" the user's brand colors away.
9. **Specific beats tasteful.** Vague intent produces generic results. "Clean and modern" is not a direction. "Linear: dark neutral surfaces, dense 13px UI type, hairline borders, one violet accent for focus" is.
10. **Craft lives in the last 10%.** Pixel alignment, real typographic punctuation, consistent number formats, designed empty states. Viewers can't name these details, but they feel their absence.
11. **Accessibility is the floor.** Legible sizes, sufficient contrast, meaning never carried by color alone. Never trade these for style.
12. **Know when to stop.** You're done when removing anything would hurt and adding anything wouldn't help. Over-designed is as generic as under-designed.

## Resolving tensions

| Tension                | Lean one way when…                                                                   | Lean the other way when…                                                              |
| ---------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| Bold vs restrained     | **Bold:** one-shot attention — launch page, title slide, cover                       | **Restrained:** repeated use, dense information, executive or financial audiences     |
| Dense vs airy          | **Dense:** experts using it daily — ops dashboard, trading view, working spreadsheet | **Airy:** first-time viewers, persuasion, anything presented                          |
| Personality vs neutral | **Personality:** consumer, brand or storytelling work                                | **Neutral:** finance, legal, data-heavy work, or when the user's brand already speaks |
| Convention vs novelty  | **Convention:** navigation, controls, chart types, reading order                     | **Novelty:** the single signature moment                                              |

When unsure, default to restrained with one bold move.

## Where generic comes from

| Symptom                                        | The decision that wasn't made               |
| ---------------------------------------------- | ------------------------------------------- |
| Everything the same weight                     | What matters most                           |
| Everything centered                            | The grid                                    |
| Gradients, glows, glassmorphism                | The color palette (effects stand in for it) |
| Emoji or icons on every heading                | Hierarchy (outsourced to ornament)          |
| Three equal cards, identical KPI tiles         | Content priority                            |
| Default chart styling, legend box, heavy grid  | What the chart is meant to say              |
| Bullet slides with topic titles ("Q3 Results") | The takeaway sentence                       |

## The director's questions

Ask these of your own work, the way a design director runs a crit:

- What do I see first — and is it the most important thing?
- Why is this here?
- Why this size, color or weight? What happens if it matches its neighbor?
- What will they remember tomorrow?
- Could I tell who made this, or is it a template?
