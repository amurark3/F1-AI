## 2. Page shell and loading (D10, D11)

- **`[year]/page.tsx`** (server):
  - Keep `revalidate = 3_600` and `generateStaticParams` (it awaits at build time only).
  - `generateMetadata` awaits only `params` and returns `{ title: `${year} F1 Season | F1 AI`, description: `The ${year} Formula 1 World Champions and every race winner.` }`. Metadata must not hold the stream.
  - The default export awaits only `params`. It sets `const latest = currentSeason()` (`@/app/lib/server/raceControl`). Then: `if (!/^\d{4}$/.test(year) || n < FIRST_SEASON || n > latest) notFound();`. Then: `return <SeasonDetailView year={n} latest={latest} seed={getSeasonDetail(year)} />`.
  - Why: a 404 needs no data. A year in range that f1db lacks (for example in January) answers `{ error }`, so each section shows the kit failure card.
- **`useChampionsSections.ts`**: add `useSeasonDetail(year: number, seed: SeasonDetail | null)`, which is `useSection<SeasonDetail>(`${API_BASE}/api/champions/${year}`, { seed, config: CONFIG })`. That is one SWR key for all four consumers, so one request.
- **`[year]/SeasonDetailView.tsx`** (client, rewritten; no data of its own). Props `{ year: number; latest: number; seed: Promise<SeasonDetail | null> }`. It holds:
  - **Crumbs.** `<nav aria-label="Seasons" className="flex items-center justify-between gap-4">`, with `CRUMB = "inline-flex min-h-11 items-center gap-2 font-mono text-[11px] font-semibold uppercase tracking-[0.16em] text-rc-ink-3 transition-colors hover:text-rc-ink"`:
    - `<Link href="/race-control/champions"><span aria-hidden="true">←</span> All champions</Link>`;
    - `<span className="flex gap-[22px]">` holding prev (`year > FIRST_SEASON`): `‹ {year-1}`, and next (`year < latest`): `{year+1} ›`. The glyphs are `aria-hidden`. Each link has `aria-label={`${y} season`}` and `prefetch={false}`. Why `prefetch={false}`: un-prerendered seasons render on demand against the backend (D12).
  - **Hero.** `<section aria-label={`${year} season`} className="mt-3">` + `<Suspense fallback={<SectionSkeleton className="h-[330px]" />}><SeasonHero …/></Suspense>`.

### 3.4 `seasonDetailModel.ts` (pure; every string computed; tests first)
Local helpers: `plural(n, word)` ("1 win" / "9 wins"); `last` = `driverLabel({ name, lastName: last_name }, "last")`; `left` = `round_count − rounds_completed`; `running` = `rounds_completed < round_count`; `pts` = `formatPoints` from `../../profiles/profilesModel`.

Export `FIRST_CONSTRUCTORS_TITLE = 1958`. Why: one season payload can't tell "before the title existed" from "no standings yet".

- `seasonEyebrow(d)`:
  - no driver → `${season} season`;
  - open → `${season} championship leader`;
  - clinched → `${season} World Champion · clinched`;
  - final → `${season} World Champion`.
- `seasonMeta(d): string | undefined`: no driver → `undefined`. Else join `[team, tail]` with `" · "` (skipping nulls; `undefined` when both are null). `tail` is:
  - open → `Leads ${afterRound(d)}; the title is still open.`;
  - decided with `decided_at` → `Title decided in round ${r}${place ? `, ${place}` : ""}.`, plus `` ` ${stillToRun(left)}.` `` when clinched;
  - decided without `decided_at` → none.
- `seasonTiles(d): SeasonTile[]` (`{ label; value: string; unit?; sub?; lead? }`). The first three need a driver:
  - `Points`, lead: `pts(points)`, unit `pts`, sub `final total` when final, else `afterRound(d)`;
  - `Wins`: `${wins}`, unit `of ${rounds_completed}`;
  - only with `runner_up`: `Lead` when open, else `Margin`, value `pts(points − ru.points)`, unit `pts`, sub `over ${driverLabel({ name: ru.name, lastName: ru.last_name }, "full")} · ${pts(ru.points)} pts` (departure 2).
  - Constructors, with `sub = `${pts(c.points)} pts${running ? ` ${afterRound(d)}` : ""}`` (departure 3):
    - decided → `Constructors' champion`, `teamLabel({ name, year: season }, "name")`;
    - undecided → `Constructors' leader`, same value;
    - null and `season < 1958` → `Constructors' champion`, `—`, sub `title awarded from 1958`;
    - null otherwise → no tile.
- `ribbonTitle(d): string | null`: no driver → `null`. Else `${plural(wins, "win")} for ${last}`, then one of:
  - open → `, title still open after round ${rounds_completed}`;
  - decided with `decided_at`, `spare = round_count − decided_at.round` → `, decided at the last round` when 0, else `, decided with ${plural(spare, "round")} to spare`;
  - decided without `decided_at` → nothing.
- `roundTicks(d): RoundTick[]`: one per round `1..round_count`. Winners are grouped by round, so two P1 rows on a round make one tick. Fields:
  - `run` (the round has a winner);
  - `team` (the first row's team);
  - `championWon` (some winner's `name === driver_champion.name`; the payload has no champion id);
  - `decider` (`round === decided_at?.round`);
  - `keep` (round 1, the decider, or `round_count`);
  - `tip`: `R${n} · ${names " / "} · ${team}`, plus ` · shared drive` for two or more winners; a round with no winner → `R${n} · still to run`;
  - `flag` on the decider: `{ text: place ? `Title decided · ${place}` : "Title decided", side: n / round_count > 0.6 ? "end" : "start" }`, else `null`.
- `ribbonLegend(d): LegendItem[]`: `{ label: `${last}'s win`, color: rc.ink }`; when `decided_at`, `{ label: "Title decided", color: rc.gold, mark: "rule" }`; when running, `{ label: "Still to run", color: rc.dim }`; then `{ label: "Bar = the winning car's team" }`. Straight apostrophes, as P6.4.
- `winnerRows(d): WinnerRow[]`: rounds ascending; `{ round, winners: RaceWinner[], team, teamId, raceName, date: dayMonth(date), decider, shared: winners.length > 1 }`. f1db's three shared drives (1951 R4, 1956 R1, 1957 R5) each have one constructor, so the first row's team stands.
- `toRunRow(d)`: `null` unless running. Else, with `a = rounds_completed + 1` and `b = round_count`: `{ span: a === b ? `R${a}` : `R${a}–R${b}`, text: `${stillToRun(left)}` }`. The en dash matches the mockup.
- `roundsAside(d)` → `${rounds_completed} of ${round_count} rounds`.
- `seasonSource(d)` → `Source: f1db`, plus `` ` · ${season} ${afterRound(d)}` `` when `0 < rounds_completed < round_count` (as P6.4's `sourceNote`).
- `dayMonth(iso: string | null)` uses `Intl.DateTimeFormat("en-GB", { day: "numeric", month: "short", timeZone: "UTC" })`: `"2026-03-08"` → `"8 Mar"`, and `null` → `""`.
