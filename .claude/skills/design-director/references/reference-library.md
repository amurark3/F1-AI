# Reference Library

Exemplars to draw from. For each: signature traits, what to steal, where it fits, and what a bad imitation looks like. Steal principles and systems, never logos, brand marks or proprietary fonts.

**Contents:** Product UI (Stripe · Linear · Apple · Vercel) · Movements and masters (Swiss · Bauhaus · Rams · Vignelli) · Data and editorial (Tufte · FT · Economist · NYT) · Presentation (Minto/McKinsey) · Direction picker

## Product UI

### Stripe

- **Traits:** a crisp grotesk; deep navy ink (≈ `#0A2540`) instead of black; generous whitespace on precise grids; rich color confined to illustration; meticulous docs tables and code blocks.
- **Steal:** navy-ink neutrals, exact spacing, clean technical diagrams, beautifully set data tables.
- **Fits:** fintech, developer tools, B2B pages, pricing, documentation.
- **Bad imitation:** the gradient mesh hero. It is the most-copied part and now reads as a template.

### Linear

- **Traits:** dark neutral surfaces; high density with calm; small (~13px) crisp UI type; hairline borders at low opacity; subtle surface steps; one restrained accent for focus and selection; motion under 150ms.
- **Steal:** density without clutter, low-contrast structure, monochrome icons, fast micro-motion.
- **Fits:** tools, internal and ops dashboards, developer products, status pages.
- **Bad imitation:** dark mode plus purple glow. Linear's restraint is the point.

### Apple

- **Traits:** one idea per screen; huge tightly tracked headlines; product imagery as the hero; vast white or black space; short declarative copy.
- **Steal:** one-idea-per-view pacing, a confident display scale, bold cropping, disciplined copy.
- **Fits:** launch pages, keynote-style decks, product storytelling.
- **Bad imitation:** minimalism with no hero. Without a great image or a great number, it's just empty.

### Vercel (Geist)

- **Traits:** black and white; Geist Sans and Mono; grid lines visible as structure; precise 1px borders; monospace metadata.
- **Steal:** the visible grid as an aesthetic, mono for labels and metadata, extreme contrast kept restrained.
- **Fits:** developer tools, technical reports, changelogs.

## Movements and masters

### Swiss / International Typographic Style (Müller-Brockmann, Hofmann)

- **Traits:** grotesk sans; modular grids; flush-left, ragged-right text; asymmetric balance; strong scale contrast; black and white plus one red.
- **Steal:** grid discipline, flush-left alignment, dramatic scale contrast, rules as structure.
- **Fits:** reports, posters, data-heavy decks — anything that should feel objective and authoritative.
- **Bad imitation:** Helvetica and red with no grid. The grid _is_ the style.

### Bauhaus

- **Traits:** circle, square and triangle; red, yellow and blue with black; geometric sans; bold color blocks; form follows function.
- **Steal:** geometric shapes as structural graphics, primary-color blocks for section identity.
- **Fits:** covers, section dividers, posters, education, playful brand moments.
- **Bad imitation:** primaries as data-series colors. They're too loud; use them for structure, not data.

### Dieter Rams / Braun

- **Traits:** "less, but better"; neutral grays and off-whites; one functional accent (Braun orange or green); ordered, honest controls.
- **Steal:** a single functional color, gridded order, and the question "is this necessary?".
- **Fits:** product UI, settings, instruments, spreadsheets — any calm tool.

### Massimo Vignelli

- **Traits:** a tiny set of typefaces used rigorously; strong grids (Unigrid); heavy black bands; diagrammatic simplification (NYC subway map).
- **Steal:** a black header band, strict type discipline, simplifying complexity into diagrams.
- **Fits:** reports, signage-like dashboards, system diagrams, maps.

## Data and editorial

### Edward Tufte

- **Traits:** maximize data-ink; remove chartjunk; small multiples; sparklines; text and graphics integrated.
- **Steal:** delete non-data ink, sparklines in tables, small multiples, annotation in place.
- **Fits:** every chart, analytical reports, dashboards.

### Financial Times

- **Traits:** warm salmon paper (≈ `#FFF1E5`); serif headlines; left-aligned insight titles over every chart; minimal gridlines; a consistent chart palette; a source line on every chart.
- **Steal:** the title → subtitle → chart → source pattern, a warm background, chart discipline.
- **Fits:** financial and economic reports, data stories.

### The Economist

- **Traits:** a small red tag at top left; horizontal gridlines only; compact sans labels; a disciplined blue palette.
- **Steal:** a small accent tag as identity, compact chart furniture.
- **Fits:** dense chart pages, briefing documents.

### NYT Graphics / The Pudding

- **Traits:** annotation-led storytelling; guided reading order; explanatory text woven into custom charts.
- **Steal:** annotation as the narrative device, one clear reading path.
- **Fits:** explanatory reports, single-insight pages.

## Presentation

### Minto / McKinsey (Pyramid Principle)

- **Traits:** answer first; action titles; one message per slide; MECE structure; source footnotes; a restrained navy-scale palette.
- **Steal:** action titles, the ghost-deck storyline, sources, MECE grouping.
- **Fits:** business decks, board updates, recommendations.
