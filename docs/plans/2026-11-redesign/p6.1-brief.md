**2.1 `GET /debrief/{year}/{round}` (rewrite `build_race_debrief` in `app/services/race_control_debriefs.py`).** Factor the schedule lookup and the race-start + 3 h gate out of `load_race_classification` into `_race_event(year, round) -> dict | None` (name, location, finished: bool); `load_race_classification` keeps its exact output (`race_control_championship.py` reads it). **Delete** `DebriefSections`, `build_debrief_headline`, `build_debrief_takeaways`, `build_podium_cause`, `build_constructor_impact`, `build_race_control_notes` and their tests (nothing else uses them). Payload:
- `year, round, race` (event name), `location`, `available` (a classification exists), `reason` (`"Round N not found for YYYY"` / `"The race hasn't been classified yet."` / null).
- `final`, `sources`, `classification`: `build_session_result(year, round, "race")`'s rows unchanged, each plus `grid: int | null` and `pit_lane: bool`.
- `grid`: `{available, fia_document}` from `race_grid.build_starting_grid(year, round)`: use its rows (`driver_code`, `position`, `pit_lane`) **only when `available and not provisional`** (f1db's sheet or the FIA's final grid; a qualifying-order stand-in would invent places gained). Otherwise every row `grid: null, pit_lane: false`, `available: false`. `fia_document` passed through.
- `titles`: from `build_standings_progression(year)`; for `drivers` then `constructors`, when `clinched.round == round`: index `i` of that round in `rounds`; entrants with `points[i]` not null sorted desc → `{table, name, team, points, lead (champion − runner-up), runner_up, races_left (clinched.races_left), provisional (rounds[i].provisional)}`. No try/except: a failure fails the endpoint (kit failure card + retry).

**2.2 `GET /debrief/{year}/{round}/laps` → new `app/services/debrief_laps.py` `build_debrief_laps`.** `load_session_laps(year, round, "R")` (cached; `OpenF1UnavailableError` propagates to the route's error envelope). None or no laps → `{available: false, reason: "OpenF1 hasn't published this race's laps yet.", total_laps: 0, drivers: [], leaders: [], trace: [], neutralisations: []}`.
- **Crossing** at the end of lap n for a car = `lap.end` (start + time); if the time is missing, the start of that car's lap n+1; else none.
- `leaders`: for n = 1…`total_laps` (highest lap with any crossing), the car with the earliest crossing of lap n → its code, `null` when no car has one.
- `trace`: the first five **classified** cars of `build_session_result(year, round, "race")` (FIA authority), matched to OpenF1 by `session.driver_by_code(code)` (skip a car OpenF1 doesn't list); `{driver_code, position, gaps}` where `gaps[n-1]` = crossing(car, n) − crossing(leader of lap n, n) in seconds, 3 dp, `null` when either is missing.
- `drivers`: `{driver_code, driver_name, team}` for every code in `leaders` and `trace` (canonical names from the OpenF1 entry).
- `neutralisations`: `race_neutralisations.lap_ranges(session.laps, session.windows)` (the Stints tab's shape `{kind: sc|vsc|red, start_lap, end_lap}`; reuse, don't copy).

**2.3 `GET /debrief/{year}/{round}/penalties` → new `app/services/debrief_penalties.py` `build_debrief_penalties`.** `with new_client()`: `find_session(client, year, round, "R")`; none → `{available: false, in_race: [], post_race: [], fia_document: null}`. Race control via `get_json(client, "race_control", {"session_key": key})` (a stored endpoint).
- **In-race** = each message matching `^FIA STEWARDS: (?P<served>PENALTY SERVED - )?(?P<penalty>.+? PENALTY) FOR CAR (?P<car>\d+) \((?P<code>[A-Z]{3})\)(?: - (?P<offence>.+?))?(?: \((?P<at>\d{1,2}:\d{2}:\d{2})\))?$` without `served` → `{lap (message lap_number), car, driver_code, driver_name, penalty (sentence case: "5 second time penalty"), seconds (from "(\d+) SECOND TIME PENALTY", else null), offence (sentence case or null), served}`; `served` = a `PENALTY SERVED` message exists for the same car and the same `at` (same penalty text when `at` is absent). Investigations, "NO FURTHER ACTION", flags never match. Ordered by lap.
- **Post-race** = `fia_documents.results.final_classification(year, round, "race")`'s `classification.penalties` (RuledNote: car, ruling, reason, document): driver via `final.driver(year, car, <that car's classification entry name or "">)`; `seconds` from `(\d+)\s+second\s+time\s+penalty` in the ruling (own regex; per note, so a converted stop-and-go reads 30); `road_position` / `position` from `build_session_result(...)["changed_after_flag"]` by driver code (null when absent). `fia_document` = `{number, url}` of that classification. **No FIA classification yet** → post-race rows come from `changed_after_flag` alone (`ruling: "{n} second time penalty"`, `reason`/`document` null). **Dedupe:** drop a post-race row whose driver has an in-race row with the same `seconds`. Ordered by document number, then car.
- Why no served lap: race control's "PENALTY SERVED" lap is the leader's lap when the message went out (Leclerc served at his lap-27 stop; the message reads lap 30), so the UI says "served" only.

**2.4 `GET /debrief/{year}/{round}/overtakes` → new `app/services/debrief_overtakes.py` `build_debrief_overtakes`.** `find_session` + `entry_list(client, key)` + `get_json(client, "overtakes", {"session_key": key})` (never stored by the read-through, so keep the rows in `analysis_cache` kind `race_overtakes`, version 1, key `"{year}:{round}"`, only when rows exist and `session_ended(session)`, as `race_context.py` does). Payload `{available, total (row count), drivers: [{driver_code, driver_name, team, made}] for made > 0, sorted by made desc then code}`; rows with no `overtaking_driver_number` are skipped. No session or no rows → `available: false`, `total: 0`.
