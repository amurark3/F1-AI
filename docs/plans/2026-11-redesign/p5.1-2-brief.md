## 3. P5.1: the progression endpoint

**Route:** `GET /api/race-control/standings/{year}/progression`.
- No query params. The client picks its own top five.
- Handler in `backend/app/api/routers/race_control.py`, after `get_drivers`:

```python
@router.get("/standings/{year}/progression")
async def get_standings_progression(year: int) -> dict:
    try:
        return await asyncio.to_thread(build_standings_progression, year)
    except Exception as exc:
        return {"year": year, "rounds": [], **client_error("api.race_control_standings_progression.error", exc, year=year)}
```

**Response** (all keys always present; example trimmed to rounds 18–19, Mexico morning):

```json
{
  "year": 2026,
  "as_of_round": 19, "provisional": true,
  "sources": [{"source": "f1db", "role": "base", "through_round": 18, "version": "v2026.18.0"},
              {"source": "openf1-session-result", "role": "points", "round": 19, "sessions": ["R"]}],
  "rounds": [
    {"round": 18, "name": "United States Grand Prix", "location": "Austin, United States", "sprint": false, "provisional": false},
    {"round": 19, "name": "Mexican Grand Prix", "location": "Mexico City, Mexico", "sprint": false, "provisional": true}],
  "drivers": {
    "entrants": [{"key": "ANT", "name": "Kimi Antonelli", "team": "Mercedes", "points": [365, 380], "positions": [1, 1]},
                 {"key": "HIR", "name": "Ryō Hirakawa", "team": "Haas", "points": [null, 1], "positions": [null, 21]}],
    "clinched": {"round": 19, "races_left": 4, "sprints_left": 0}},
  "constructors": {
    "entrants": [{"key": "Mercedes", "name": "Mercedes", "team": "Mercedes", "points": [607, 630], "positions": [1, 1]}],
    "clinched": null}
}
```

- `rounds` covers rounds 1…`as_of_round` (none when `as_of_round` is null).
  - `name`, `location` and `sprint` come from `season_events(year)`; they are `null` when the calendar can't be read.
  - `provisional` is true when f1db's published table doesn't hold the round.
- `entrants` are the current table's rows, in order (`standings.drivers` / `standings.teams`). `points[i]` and `positions[i]` belong to `rounds[i]`, and are `null` where the entrant had no row that round (a driver before his first race).
- `clinched` is `null` while the title is open, or when that can't be known.
  - `races_left` and `sprints_left` count the calendar events after the clinch round (`is_sprint` for sprints). Both are `null` without a calendar.
  - Shortcut to note in a code comment: f1db's calendar has no session times before 2024, so `is_sprint` reads false there. The page only shows the current season.

**Computation:** new module `backend/app/services/race_control/progression.py`, about 120 lines, with a module docstring stating the rule below.

1. `standings = current_standings(year)`. It is cached and is the same table `/teams/{year}` serves.
2. Each round's table:
   - Rounds f1db holds: f1db's published table (new `f1db_standings.standings_by_round`).
   - Rounds after f1db's base: the computed tables (new `CurrentStandings.round_tables`).
   - Sprints need no handling of their own: f1db's per-round table and `standings_rounds` both count a weekend's sprint inside its round.
3. **Clinch round:**
   - f1db's own decider flag (`race.drivers_championship_decider` / `constructors_championship_decider`) when f1db marks one.
   - Otherwise, the first computed round where `table_reach.TableReach(rows, scoring, table_reach.remaining_after(year, round)).decided()` is true. That is the shared P0.6 title rule, unchanged.
   - Why not the rule everywhere: f1db's calendar has no session times before 2024, so `points_left` counts nothing left and the rule "clinches" every pre-2024 title on round 1 (checked on 2021–2023).
   - The rule matches f1db's flags exactly for 2024–2026: 2024 drivers R22 and constructors R24; 2025 constructors R18 and drivers R24; 2026 drivers R19 and constructors R20.
4. Calendar: `{e["round"]: e for e in strategy_context.season_events(year)}`. Wrap it in `try/except Exception`: log a warning and use `{}`. A missing calendar never fails the endpoint.
5. Ruff's 4-argument budget: pass per-championship inputs as one frozen dataclass:

```python
@dataclass(frozen=True)
class _Table:
    rows: tuple[Standing, ...]
    published: dict[int, dict[str, tuple]]
    computed: tuple[tuple[int, tuple[Standing, ...]], ...]
    decider: int | None
    scoring: Scoring
```

   For drivers it is built from `title_rule.DRIVERS`; for teams from `title_rule.CONSTRUCTORS`.

**`heroModel(table, teams, stakes?, progression?, year)`:**

- **Leader row:**
  - drivers: `teams.drivers[0]`, with the name from `<DriverName variant="full">`;
  - constructors: `teams.teams[0]`, with the name from `<TeamName>`.
  - `lead` is `rows[0].points - rows[1].points`, through `formatPoints`.
- **Big figure:** `formatPoints(points)` with the unit `pts`.
- **Eyebrow (gold):**
  - decided: drivers `${year} World Champion`, constructors `${year} Constructors' Champion`;
  - open: `Championship leader` or `Constructors' leader`.
- **Meta** (team swatch first, the swatch only for drivers): drivers `${team} · ${wins} win(s) from ${as_of_round} races`; constructors `${wins} win(s) from ${as_of_round} races`.
- **`heroLine`** returns `{ strong?: string; text: string }`:
  - **Decided, with `clinched`:**
    - `strong` = `Clinched in ${venue}`.
    - spare = `races_left` null → nothing; 0 → ` at the final round`; otherwise ` with ${r} race(s)` plus ` and ${s} sprint(s)` when s > 0, plus ` to spare`.
    - tail = without stakes `: ${lead} points clear.`; with `max_available` 0 → `, and won it by ${lead} points.`; otherwise `: ${lead} points clear, and only ${max} left to win.`
    - On the R19 fixtures this gives: **Clinched in Mexico City** with 4 races to spare: 119 points clear, and only 100 left to win.
  - **Decided, no `clinched`:** `strong` "Clinched", plus the same tail.
  - **Open, with stakes:** `clinchLine(stakes[table], nextVenue, table).text`, verbatim (P0.6; P5.3b may replace it).
  - **No stakes:** `${lead} points clear of ${p2} after round ${n}.`, or with `lead` 0, `Level on points with ${p2}, ahead on count-back.`
- **Side tiles** (`StatTile`, vertical stack, `lg:border-l lg:pl-7`):
  1. **Decided:** "Fight for second". Value is P2 − P5 points (`rows.slice(1, 5)`; leave the tile out when fewer than 2). Sub is their surnames, comma-separated. On R19: 16, "Verstappen, Hamilton, Russell, Leclerc".
     **Open:** "Rivals in reach". Value is `stakes[table].rivals_alive`. Sub is the surnames of the `alive` contenders below P1, plus ` +${k} more` when `rivals_alive` exceeds those listed. Left out without stakes.
  2. **The other championship** ("Constructors" or "Drivers"). Value is its P1 − P2 points. Sub is `${p1} clinched` when it is decided, otherwise `${p1} over ${p2}`, plus ` · ${max} left` with stakes. On R19: 126, "Mercedes over Ferrari · 172 left".
  3. **"Races left".** Value is `stakes.races_left`. Sub: 0 races → "season complete"; 0 sprints → "no sprints"; otherwise `${s} sprint(s)`. Left out without stakes.
- **`driverItems(rows, decided)` / `teamItems(rows)`:**

  - `aside` = `—` for P1, otherwise `−${formatPoints(gap)}` (U+2212);

  - `detail` = the code (drivers only);
  - `label` = `<DriverLink code name><DriverName variant="full"/></DriverLink>` or `<TeamLink id name><TeamName/></TeamLink>`;
  - `tag` = `<StateTag tone="gold">Champion</StateTag>` on P1 when decided.
