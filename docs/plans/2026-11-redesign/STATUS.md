  - **Tie edge, implemented exactly:** a lead equal to the points left can only be bridged one way: the rival takes the maximum in every session left (a win per Grand Prix, a win and a second for a team) and the leader scores nothing. Level on points, the count-back decides, and that run fixes what the rival adds. The leader's worst case adds no places, because a classified finish outside the points can only help him in a count-back. So the title is decided only when the leader still wins that count-back outright. A count-back level all the way down goes to the FIA's own criteria, so that rival stays in. Sprint places take no part, as in `standings_table`. Why: the old code never called a tie decided. That was safe, but wrong once the count-back has already settled it, e.g. a season ending level on points.
