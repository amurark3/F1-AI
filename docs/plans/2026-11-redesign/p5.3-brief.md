## 2. Domain rules (decided)

1. **Scoring:** a Grand Prix pays 25-18-15-12-10-8-6-4-2-1 and a sprint 8-7-6-5-4-3-2-1. f1db confirms this: every 2025 and 2026 race winner scored exactly 25. 2024 still has the fastest-lap point (26/19/16 rows). So there is **no fastest-lap point**, and `title_rule.DRIVERS` (25/8) and `CONSTRUCTORS` (43/15: a one-two) are right. `FIRST_YEAR = 2025`: for an earlier year the endpoint returns null championships and computes nothing, because those years used other rules (the fastest-lap point in 2019–24, double points in 2014, a 3-2-1 sprint in 2021). From 2025 on, points are whole numbers, so "+1" is the next possible score.
2. **Alive / decided:** these keep `title_rule.can_still_beat` unchanged: the rival's best (a win, or a one-two, everywhere) against a leader who scores nothing, with an exact tie decided by the FIA count-back (most wins, then most seconds, …; sprints take no part). A title is decided when, in a table of at least 2 rows, no rival can still beat the leader.
3. **Step per weekend, not per session.** `standings_rounds` adds a round only once its race has ended, with its sprint, never alone. So the table always reads "after round N", the next event is the next round's weekend (sprint + race), and the wording is "clinch in São Paulo".
4. **Margin against one rival X at the next event E** (the leader's lead now is `lead`; `after` = the sessions after E; `left_after = max_points(after)`). The leader settles it against X at E for certain when `L_E − X_E ≥ margin`. The count-back at a finish level on points can depend on E's places, so it has three states:
   - `holds` = True when the leader wins the count-back even if X adds the event's best places (`race_places × at.races`) plus the perfect run after E (`race_places × after.races`) and the leader adds nothing.
   - `holds` = None ("depends") when it fails in that worst case but holds if the leader adds the event's best places and X adds nothing at E.
   - `holds` = False otherwise.

   Then `margin = left_after − lead + (0 if holds is True else 1)` and `countback = holds is None`. A finish exactly one point short of `margin` goes to the count-back on E's places. **Recommendation (why):** the quoted margin is always sufficient, so we never promise a clinch that a count-back could undo. It is also exact whenever the count-back is settled in advance (Mercedes' 12 wins against Ferrari's 2), and the flag states the one uncertain point instead of hiding it.
5. **Possible at E:** this is exact and uses the best case. The leader scores `max_points(at)` and adds the event's best places, every rival scores nothing, and then no rival can still beat the leader (`can_still_beat` with `after`). **Earliest** is the first upcoming event where that best case, accumulated through it, decides the title. `possible` is the same as `earliest` being the next event.
6. **Provisional:** the payload carries `standings.meta()`. `decided_at.provisional` is true when the clinch round is the table's `as_of_round` and the table is provisional. A clinch at an earlier round that f1db holds is confirmed.

### 3.1 Pure rule: extend `backend/app/data/title_rule.py` (one source of truth, no I/O)

Add the following, and a docstring paragraph for the event rule (§2.4–2.5):

```python
@dataclass(frozen=True)
class Need:
    """What the leader must do at one event against a rival still able to beat them."""
    rival: Standing
    margin: float      # the leader settles it against `rival` by outscoring them by at least this (≤ 0: by not being outscored by more than -margin)
    countback: bool    # a finish exactly one point short of `margin` turns on the count-back, i.e. on this event's places

def total(parts: Iterable[Remaining]) -> Remaining
def decided(rows: tuple[Standing, ...], remaining: Remaining, scoring: Scoring) -> bool   # len(rows) > 1 and no row can_still_beat rows[0]
def needs_at(rows, at: Remaining, after: Remaining, scoring) -> tuple[Need, ...]
def can_settle_at(rows, at: Remaining, after: Remaining, scoring) -> bool
def earliest(rows, upcoming: tuple[Remaining, ...], scoring) -> int | None   # index into upcoming
```

- `needs_at` covers every `row` in `rows[1:]` with `can_still_beat(leader, row, total((at, after)), scoring)`. Each gets `_holds_tie(leader, rival, here, run)`, where `here = scoring.race_places * at.races` and `run = scoring.race_places * after.races` (4 args, which keeps it within PLR0913), and then margin and countback as in §2.4. Sort by `-margin`; the sort is stable, so ties keep table order. Reuse `countback` from `standings_table`, and share the comparison with `_wins_tie` if that falls out naturally.
- `can_settle_at`: `best = replace(leader, points=leader.points + max_points(at, scoring), finishes=(*leader.finishes, *here))`, then `not any(can_still_beat(best, row, after, scoring) for row in rows[1:])`.
- `earliest`: returns the first `i` with `can_settle_at(rows, total(upcoming[: i + 1]), total(upcoming[i + 1 :]), scoring)`.

### 3.4 Builder: new `backend/app/services/race_control/clinch.py` (≤ 200 lines)

```python
FIRST_YEAR = 2025
@dataclass(frozen=True)
class Season:
    events: tuple[dict, ...]   # season_events(year)
    as_of_round: int           # 0 before any
    provisional: bool
def build_clinch(year: int) -> dict
```

Algorithm:
1. If `year < FIRST_YEAR`, return `{"year", "as_of_round": None, "provisional": False, "sources": [], "drivers": None, "constructors": None}` without touching f1db or OpenF1.
2. `standings = current_standings(year)`; `events = tuple(season_events(year))`, letting `CalendarUnavailableError` propagate to the router. `through = standings.as_of_round or 0`.
3. Replay: `reduce(add_round)` over `season_scores(year, through - 1)` in round order, keeping `(round, Table)` after each round. These are the earlier tables; the table at `through` is always `standings`' own.
4. For each championship (`standings.drivers`/`DRIVERS`, `standings.teams`/`CONSTRUCTORS`), `_title(rows, season, championship, earlier_rows)`:
   - If `len(rows) < 2` or `rows[0].points <= 0`, return `None`.
   - `upcoming = [e for e in events if e["round"] > through]`; `parts = [Remaining(*paying_sessions(e, None)) for e in upcoming]`; `left = total(parts)`.
   - `{"decided", "leader": {**entrant, "points"}, "max_available": max_points(left), "next", "earliest", "decided_at"}`.
   - **Open:** `next` = `{**_event(upcoming[0]), "races", "sprints", "max_points": max_points(parts[0]), "possible": earliest_index == 0, "needs": [need_row…]}`, using `needs_at(rows, parts[0], total(parts[1:]))`. `earliest` = `_event(upcoming[i])` or `None`. `decided_at: None`. With no upcoming event and not decided (an exact season-end count-back tie), `next`, `earliest` and `decided_at` are all `None`.
   - **Decided:** `next: None`, `earliest: None`. `decided_at` comes from walking `earlier + [(through, rows)]` in round order. Take the first round `k` whose table is `decided(rows_k, _after(events, k))`. If the table before it in the list is not round `k − 1` (round 0 when `k` is first), return `None`: f1db trails by more than one round and the clinch round is unknown. Mark that line `# shortcut: rounds between f1db's last and as_of_round have no table; read them from current_standings if f1db ever lags more than a round`. Otherwise `{**_event(event k), "lead": rows_k[0].points - rows_k[1].points, "left": max_points(after_k), "races_to_spare": after_k.races, "sprints_to_spare": after_k.sprints, "provisional": standings.provisional and k == through}`.
   - `_event(e) = {"round", "name", "venue": e["location"].split(",")[0].strip()}`. The Command Center derives its venue the same way.
5. Return `{"year", **standings.meta(), "drivers", "constructors"}`.

No extra cache: `current_standings` is TTL-cached, and the rest is local SQLite (one calendar read and one results query).

    - Clauses with `m ≤ 0`: `{R} {outscores} them by {t} or more`, where `t = 2−m` with ` ({1−m} goes to count-back)` when `countback`, otherwise `t = 1−m`. Join them with ", or " after `, unless ` (` unless ` when there are no positives).

  - `decidedSentence(d)` returns `{strong, rest}`:

  - `stayInItSentence(table, leader, need)`:
    - `m > 0`: `{R} {stays} in it unless {L} {outscores} them by {m} or more` + ` ({m−1} goes to count-back)` when `countback`, then ".".
    - `m ≤ 0`: `{R} must outscore {L} by {t} or more to stay in it` (t as above) + ` ({1−m} goes to count-back)` when `countback`, then ".".
  - `entrantClause(table, title, entrant)` (match a driver by `code`, a team by `name`):
    - champion: `Clinched in {venue} with {spare} to spare.` / `… at the final round.` (or `Provisionally …`).

    - a rival in `next.needs` with `margin ≤ next.max_points`: `stayInItSentence`.

    - everyone else: `null`.
