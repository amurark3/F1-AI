## 1. Goal and scope

A panel, **"FIA decisions"**, on the Command Center and on the Grand Prix hub's Weekend tab. It lists the round's stewards' decisions and summonses, starting grids and deleted-lap sheets, newest first, each row linking to its FIA PDF. During a live weekend it refreshes itself.

**Out of scope (named, not built):** a filter (`Segmented`) by kind; a "new since you opened the page" mark or announcement; incremental polling with `?after=` (the whole payload is ~100 KB and cached 60 s server-side); a "last checked" time (the backend has no ingest-run record, see §9 Q2); classifications, entry lists, Pirelli, power-unit and other documents (counted in the footer, not listed); linking names to driver pages.

## 2. API contract

`GET /api/weekend/{year}/{round}/feed` (`backend/app/api/routers/weekend.py`, `get_weekend_feed`; data from `backend/app/data/fia_documents/feed.py`, `weekend_feed`). `year` 2019–2100 (422 below 2019), `round` 1–30. Optional `?after=` (unused here).

```jsonc
{
  "year": 2026, "round": 19,
  "event": "Mexico City Grand Prix",   // null before the round's first document
  "latest": 86,                        // highest document number, null when none
  "events": [                          // newest first (by number; a null number sorts last)
    {
      "number": 79,                    // from the title "Doc 79 - …"; may be null
      "title": "Doc 79 - Infringement - Car 81 - Causing a collision",
      "kind": "penalty",               // penalty | grid | classification | deleted_laps | entry_list | power_unit | pirelli | timetable | other
      "published": "02.11.26 00:57",   // as fia.com prints it: Paris wall-clock time, "" when unlisted
      "published_at": "2026-11-01T23:57:00+00:00",   // NEW (B1): UTC ISO, null when `published` doesn't parse
      "url": "https://www.fia.com/system/files/decision-document/….pdf",
      "withdrawn": null,               // reason string when taken back (B2 widens it)
      "data": { … },                   // what the parser read, by kind; null when no parser / not a grid / unread
      "unread": null                   // why the PDF couldn't be read or parsed; never show this text (may be internal)
    }
  ]
  // on failure: same keys, empty events, plus "error" and "error_id" (HTTP 200) → useSection reports it as failed
}
```

`data` by kind (frozen dataclasses through `asdict`; tuples arrive as arrays):

- **`penalty`** (`parsers/stewards.py`, `StewardsDecision`): `document`, `status` (`"summoned"` | `"decided"`), `car`, `driver` (as printed, e.g. "Oscar Piastri", or null), `competitor` (team as printed, or null), `session` (null on a summons), `incident_time`, `offence` ("Causing a collision"), `articles` (string[]), `decision` (the decision line as printed; null on a summons), `outcomes` (`{ kind, value }[]`), `hearing` ("19:00", circuit local time; summons only). Outcome kinds: `disqualified`, `pit_lane_start`, `back_of_grid`, `grid_drop` (value = places), `time_penalty` (seconds), `stop_and_go`, `drive_through`, `reprimand`, `warning`, `fine` (euros), `penalty_points`, `no_further_action`.
- **`deleted_laps`** (`parsers/deleted_laps.py`, `DeletedLaps`): `document`, `session`, `date`, `reason` (`"track_limits"` | `"yellow_flags"` | `"other"`), `fact`, `laps` (`{ car, turn, entrant, time_of_day, lap_time | null }[]`; `entrant` runs the driver into the team: "Lance Stroll Aston Martin Aramco F1 Team").
- **`grid`** (`parsers/grids.py`, `StartingGrid`), only for "Starting Grid" titles; parc fermé reports and permissions to start keep the `grid` kind with `data: null`: `document`, `final`, `slots`, `pit_lane` (`{ car, entrant }[]`), `notes`, `penalties` (`RuledNote[]`: `{ car, ruling, reason | null, document | null }`, e.g. `{ car: 77, ruling: "50 place grid penalty", reason: "Additional power unit elements have been used", document: 17 }`).

### 2.1 Backend work (do it first; both in `feed.py`, tests in `tests/test_fia_documents_feed.py`)

- **B1 `published_at`.** fia.com prints Paris wall-clock time with no zone (STATUS left this to P7.4). Evidence: Mexico 2026 Doc 86, the Final Race Classification, reads "02.11.26 02:50"; DATA_SOURCES.md has it at 19:50 circuit time (UTC−6), i.e. 01:50 UTC = 02:50 CET. Doc 67, the final starting grid, reads "01.11.26 20:00" = 13:00 circuit time, an hour before the 14:00 start. Add to `document_event` `"published_at": published_at(document.published)` with:
  ```python
  FIA_ZONE = ZoneInfo("Europe/Paris")
  def published_at(published: str) -> str | None:
      """fia.com's printed time ("02.11.26 02:50", Paris wall clock) in UTC, ISO; ``None`` when it doesn't parse."""
      try:
          local = datetime.strptime(published.strip(), "%d.%m.%y %H:%M").replace(tzinfo=FIA_ZONE)
      except ValueError:
          return None
      return local.astimezone(UTC).isoformat()
  ```
  Tests: Doc 79 → `"2026-11-01T23:57:00+00:00"`; Doc 86 → `"2026-11-02T01:50:00+00:00"`; a summer time (`"05.07.26 15:00"` → `"2026-07-05T13:00:00+00:00"`, CEST); `""` and `"soon"` → `None`. Update the module docstring's event description. If CI lacks the zone database, add a pinned `tzdata` to `requirements-ingest.txt` (don't add it pre-emptively).
- **B2 withdrawal notices.** Today `withdrawn` covers only a document taken off the event page or marked in its title (`listing.py`). A later document that says "Document 44 is withdrawn" or "This decision replaces Document 37" (`rescission.withdrawn_numbers(text, own_number)`, already used by `power_units/documents.py`) is ignored, so the feed would show a rescinded penalty as standing. Tests: the Mexico weekend has no withdrawals (`all(item["withdrawn"] is None …)`; verified on the fixture); add a held notice ("Doc 90 - Decision - Withdrawal of Document 79", text "Document 79 is withdrawn.") → Doc 79 reads `"withdrawn by Doc 90"`; a document already withdrawn by the page keeps its own reason.
