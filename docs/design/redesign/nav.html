  • No accordions. Every link shows; the groups are headings, so the drawer reads as the whole map.
  • Click, not hover. One menu open at a time; arrows move, Escape closes and returns focus to the trigger.
  • The trigger shows where you are. On any Races page, "Races" carries the red rule; the current item has it inside the menu.
  • The round travels. Each "This race" link carries ?round=; Debrief and Rewind wait for a race result and say so.
  • Routes don't change. Old links keep working; only labels move: "Debriefs" → "Debrief", "Teams" → "Teams & drivers".
