# Plan: ActivityKit Live Activity Declaration

**Phase:** 04 — Live Race Experience
**Task:** 04-01
**Requires:** none

## Goal

Declare the `RaceLiveActivityAttributes` struct and the `RaceLiveActivityView` widget (with Dynamic Island compact, expanded, and minimal views) in a new file `RaceLiveActivity.swift`, add it to the existing `F1AIWidgets` WidgetBundle body, and add `NSSupportsLiveActivities` to `project.yml` so the app can start Live Activities.

## Requirements Satisfied

- LIVE-01: Dynamic Island shows current driver position, gap to leader, current lap, and safety car status
- LIVE-02: Dynamic Island compact and expanded views update in real-time from WebSocket timing data (declaration step — lifecycle wired in 04-02)

## Context

**Existing widget extension:** `ios/F1AIWidgets/NextRaceWidget.swift` already has `@main struct F1AIWidgets: WidgetBundle`. Do NOT create a new `@main`. Add `RaceLiveActivityView()` to the existing bundle body.

**project.yml:** The main app target uses `GENERATE_INFOPLIST_FILE: YES`. Live Activities require `INFOPLIST_KEY_NSSupportsLiveActivities: YES` added under `targets.F1AI.settings.base`. After editing `project.yml`, regenerate the Xcode project with `xcodegen generate` from the `ios/` directory.

**Target membership:** `RaceLiveActivity.swift` must be a member of BOTH `F1AI` AND `F1AIWidgets` targets. After creating the file, open Xcode's File Inspector and check both targets under "Target Membership". Build error "cannot find type 'RaceLiveActivityAttributes' in scope" means a target is missing.

**ContentState fields needed by compact view:** `trackedDriver` (abbreviation), `trackedPosition`, `trackedGap`, `currentLap`, `totalLaps`, `sessionStatus`. These are populated by `LiveActivityService` in 04-02 from the existing `LiveTimingService` data.

**Dynamic Island compact view decision (per CONTEXT.md):** Compact leading shows driver abbreviation, compact trailing shows position + lap number. Expanded leading shows large position number + driver name. Expanded trailing shows lap fraction. Expanded bottom shows session status colored by state (red for safety car/red flag, yellow for VSC, white for normal).

**Lock screen banner:** Required by ActivityKit alongside the Dynamic Island views. Render a simple horizontal layout with the same data.

## Implementation Steps

### Step 1: Create RaceLiveActivity.swift

**File:** `ios/F1AIWidgets/RaceLiveActivity.swift`
**Action:** create
**Changes:**
- Add `import ActivityKit`, `import WidgetKit`, `import SwiftUI`
- Declare `struct RaceLiveActivityAttributes: ActivityAttributes` with static properties `raceName: String`, `round: Int`, `year: Int`
- Declare `struct ContentState: Codable, Hashable` nested inside with: `var trackedDriver: String`, `var trackedPosition: Int`, `var trackedGap: String` (e.g. "LEADER" or "+3.4s"), `var currentLap: Int`, `var totalLaps: Int`, `var sessionStatus: String`, `var isLeader: Bool`
- Declare private `func statusColor(_ status: String) -> Color` returning `.red` for "safety car"/"red flag", `.yellow` for "vsc"/"virtual safety car", `.white` for all others (case-insensitive comparison)
- Declare `struct RaceLiveActivityView: Widget` with `let kind = "RaceLiveActivity"` and an `ActivityConfiguration(for: RaceLiveActivityAttributes.self)` body
- Lock screen banner closure: `HStack` with `Text("P\(context.state.trackedPosition)")` font `.system(size: 20, weight: .black)`, `Text(context.state.trackedDriver)` font `.system(size: 14, weight: .bold, design: .monospaced)`, `Spacer()`, `Text("LAP \(context.state.currentLap)/\(context.state.totalLaps)")` font `.system(size: 12, design: .monospaced)`. Apply `.padding()` and `.activityBackgroundTint(Color.black)`
- Dynamic Island closure using `DynamicIsland { ... } compactLeading: { ... } compactTrailing: { ... } minimal: { ... }`:
  - `compactLeading`: `Text(context.state.trackedDriver).font(.system(size: 12, weight: .bold, design: .monospaced))`
  - `compactTrailing`: `Text("P\(context.state.trackedPosition) L\(context.state.currentLap)").font(.system(size: 11, weight: .bold, design: .monospaced))`
  - `minimal`: `Text("P\(context.state.trackedPosition)").font(.system(size: 11, weight: .black))`
  - Expanded `.leading` region: `VStack(alignment: .leading, spacing: 2)` with `Text("P\(context.state.trackedPosition)")` font `.system(size: 28, weight: .black)` and `Text(context.state.trackedDriver)` font `.system(size: 13, weight: .bold, design: .monospaced).foregroundStyle(.secondary)`
  - Expanded `.trailing` region: `VStack(alignment: .trailing, spacing: 2)` with `Text("LAP \(context.state.currentLap)/\(context.state.totalLaps)")` font `.system(size: 12, weight: .black, design: .monospaced)` and `Text(context.state.trackedGap)` font `.system(size: 11, design: .monospaced).foregroundStyle(.secondary)`
  - Expanded `.bottom` region: `Text(context.state.sessionStatus.uppercased()).font(.system(size: 10, weight: .bold)).tracking(1).foregroundStyle(statusColor(context.state.sessionStatus))`

### Step 2: Register RaceLiveActivityView in the WidgetBundle

**File:** `ios/F1AIWidgets/NextRaceWidget.swift`
**Action:** modify
**Changes:**
- In the existing `@main struct F1AIWidgets: WidgetBundle`, add `RaceLiveActivityView()` to the `body` after `NextRaceWidget()`:
  ```swift
  var body: some Widget {
      NextRaceWidget()
      RaceLiveActivityView()
  }
  ```
- Do NOT add `@main` to `RaceLiveActivityView`. It must be a plain `struct` conforming to `Widget`, added to the bundle body only.

### Step 3: Add NSSupportsLiveActivities to project.yml

**File:** `ios/project.yml`
**Action:** modify
**Changes:**
- Under `targets.F1AI.settings.base`, add two new keys after the existing `ASSETCATALOG_COMPILER_APPICON_NAME` line:
  ```yaml
  INFOPLIST_KEY_NSSupportsLiveActivities: YES
  INFOPLIST_KEY_NSSupportsLiveActivitiesFrequentUpdates: YES
  ```
- Run `xcodegen generate` from the `ios/` directory after saving to regenerate `F1AI.xcodeproj`

### Step 4: Set RaceLiveActivity.swift target membership

**File:** `ios/F1AI.xcodeproj/project.pbxproj`
**Action:** modify (via Xcode UI or manual pbxproj edit)
**Changes:**
- Open Xcode, select `RaceLiveActivity.swift` in the Project Navigator
- In the File Inspector (right panel), under "Target Membership", check BOTH `F1AI` and `F1AIWidgets`
- Alternatively, add the file's UUID to both targets' `PBXSourcesBuildPhase` sections in `project.pbxproj` — use the same pattern as other dual-target files if any exist, or follow Xcode's drag-to-both-targets approach
