# Plan: Favorite Driver Settings

**Phase:** 04 — Live Race Experience
**Task:** 04-03
**Requires:** 04-01

## Goal

Add a "Live Race Tracking" section to the existing `NotificationSettingsView` with a text field where users enter their favorite driver abbreviation (e.g. "VER"). The value is stored in `UserDefaults` via `@AppStorage("favoriteDriver")` and is read by `LiveActivityService` (04-02) to determine which driver the Dynamic Island tracks.

## Requirements Satisfied

- LIVE-01: Dynamic Island shows current driver position, gap to leader, current lap — the tracked driver is the user's configured favorite (falls back to race leader if none set)

## Context

**Existing settings file:** `ios/F1AI/Views/Settings/NotificationSettingsView.swift`. It already uses `@AppStorage("notificationAdvanceMinutes")` — follow the identical pattern for `@AppStorage("favoriteDriver")`.

**Storage key:** `"favoriteDriver"` — this exact string is read by `LiveActivityService` via `UserDefaults.standard.string(forKey: "favoriteDriver")`. The key must match exactly.

**UI approach:** A `TextField` accepting a driver abbreviation (3-letter uppercase, e.g. "VER", "HAM", "LEC"). Use `.autocorrectionDisabled()` and `.textInputAutocapitalization(.characters)` so input is auto-uppercased without autocomplete interference. Per the locked decision in CONTEXT.md: the setting lives in the App Settings screen (the existing Notifications settings sheet), alongside existing notification settings.

**Validation:** No hard validation — just store whatever string the user enters. `LiveActivityService` already handles "not found" by falling back to race leader. The footer text explains this behavior.

**No driver list picker needed:** CONTEXT.md deferred a full picker in favor of a text field. Do not add a curated driver list.

## Implementation Steps

### Step 1: Add favorite driver text field to NotificationSettingsView

**File:** `ios/F1AI/Views/Settings/NotificationSettingsView.swift`
**Action:** modify
**Changes:**
- Add `@AppStorage("favoriteDriver") private var favoriteDriver: String = ""` as a property on `NotificationSettingsView`, alongside the existing `@AppStorage("notificationAdvanceMinutes")` declaration
- Add a new `Section` to the `Form` body, placed BEFORE the existing "Advance Notice" section (so it appears at the top of the settings sheet):
  ```swift
  Section {
      TextField("Driver abbreviation (e.g. VER)", text: $favoriteDriver)
          .autocorrectionDisabled()
          .textInputAutocapitalization(.characters)
  } header: {
      Text("Live Race Tracking")
  } footer: {
      Text("Dynamic Island tracks this driver during live sessions. Leave blank to track the race leader.")
  }
  ```
- No other changes to the file — existing notification sections remain as-is
