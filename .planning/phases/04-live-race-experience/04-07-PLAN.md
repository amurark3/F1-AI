# Plan: Lap Count Integration

**Phase:** 04 — Live Race Experience
**Task:** 04-07
**Requires:** 04-02

## Goal

Fetch current lap number from the OpenF1 `/v1/laps` endpoint inside the backend WebSocket poll loop, broadcast it as part of a `{"type": "session_status"}` message, and surface it in the Dynamic Island compact view ("L34/57") via the existing `SessionStatus` model that `LiveTimingService` already handles.

## Requirements Satisfied

- LIVE-01: Dynamic Island shows current lap (the "current lap" field in the compact view requires this data)
- LIVE-02: Dynamic Island compact and expanded views update in real-time — lap number is part of that real-time update

## Context

**Root cause:** `_poll_openf1_positions` at line 761 of `routes.py` only queries `/v1/position`. The existing `SessionStatus` Swift model has `lap: Int?` and `totalLaps: Int?` but the backend's `live_timing` handler never sends a `{"type": "session_status"}` message — so these fields are always `nil` on iOS.

**OpenF1 `/v1/laps` endpoint (LOW confidence — verify at runtime):** `GET https://api.openf1.org/v1/laps?session_key={key}` returns an array of lap objects with fields including `driver_number`, `lap_number`, `date_start`. To get the current lap, take `max(entry["lap_number"])` across all entries for the session. This gives the highest completed lap number.

**Total laps:** OpenF1 `/v1/sessions?session_key={key}` returns session metadata including `total_laps` (field name to verify at runtime — may be `laps` or `number_of_laps`). The existing `_find_openf1_session()` already calls `/v1/sessions` — refactor it to also return `total_laps`.

**Approach:** Add a new async helper `_fetch_lap_info(session_key: str) -> dict` that returns `{"lap": int, "total_laps": int}`. Call it in the `while True` poll loop alongside `_poll_openf1_positions`. Broadcast the result as `{"type": "session_status", "data": {"status": "started", "lap": N, "total_laps": M}}`. The iOS `LiveTimingService` already handles `"session_status"` messages — it decodes them into `SessionStatus` and publishes to `LiveTimingViewModel.sessionStatus`, which `LiveActivityService` reads in `update()`.

**Fall back gracefully:** If the `/v1/laps` call fails or returns an empty array, send `{"lap": null, "total_laps": null}` in the session_status message. The Dynamic Island will display `currentLap: 0` and `totalLaps: 0` from `ContentState`, which renders as "L 0/0". This is acceptable — better than crashing. The research notes this is LOW confidence territory.

**Poll frequency:** Lap number changes at most once per ~90 seconds. Fetching it every 8-second WebSocket cycle is wasteful. Fetch it every Nth cycle — or just fetch it alongside positions and cache the last known value in `_commentary_state[room]`. Use the cached value if the laps fetch fails.

**`_find_openf1_session` refactor:** Currently returns `str | None` (the session key). Refactor to return `tuple[str, int] | None` (session_key, total_laps). Update all callers (only one caller: `live_timing`).

**`session_status` message:** The backend currently does NOT send `session_status` messages. After this plan, it will. The iOS `LiveTimingService` already handles it because the `LiveTimingData` decoder already has the `.sessionStatus` case. The web `useLiveTiming` hook (04-06) also already handles `"session_status"` — `setSessionStatus(msg.data)`.

### Step 2: Add _fetch_current_lap() helper

**File:** `backend/app/api/routes.py`
**Action:** modify
**Changes:**
- Add after `_poll_openf1_positions()`:
  ```python
  async def _fetch_current_lap(session_key: str) -> int:
      """
      Fetch the highest completed lap number for the session from OpenF1 /v1/laps.
      Returns 0 on failure or empty response (field names verified at runtime).
      """
      try:
          async with httpx.AsyncClient(timeout=OPENF1_HTTP_TIMEOUT_SECONDS) as client:
              resp = await client.get(
                  "https://api.openf1.org/v1/laps",
                  params={"session_key": session_key},
              )
              if resp.status_code != 200:
                  return 0
              data = resp.json()
              if not data:
                  return 0
              # Take the maximum lap_number across all drivers' lap entries
              lap_nums = [entry.get("lap_number", 0) for entry in data if entry.get("lap_number")]
              return max(lap_nums) if lap_nums else 0
      except Exception as e:
          logger.warning("openf1.laps_fetch_error", error=str(e))
          return 0
  ```
